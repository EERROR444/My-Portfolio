# Aryan Singh Parmar - Personal Portfolio Website

A modern, responsive, high-performance portfolio website built for **Aryan Singh Parmar**, B.Tech student in Artificial Intelligence and Machine Learning (AIML) at Technocrats Institute of Technology (Excellence), Bhopal.

---

## 🌟 Highlights & Features

- **Personalized & Complete Profile**: Features real academic credentials, verified projects, certifications (SAP & IBM), and high-resolution portrait photo.
- **Modern Glassmorphic Dark & Light Theme**: Built-in instant theme switcher with local storage persistence.
- **Dynamic Typing Animation**: Interactive header highlighting computer vision, full-stack development, and AI engineering.
- **Project Deep-Dive Modals**: Architectural breakdown of *AI Virtual Painter*, *AI Censor Bot*, and *Backend Suite*.
- **Integrated Resume**: One-click download of the real verified `Aryan_Singh_Parmar_Resume.pdf`.
- **One-Click Contact & Social Connect**: Copy email to clipboard with animated toast notification, direct WhatsApp link, and pre-formatted mailto form.
- **Zero Heavy Dependencies**: Pure semantic HTML5, modern CSS3, and vanilla ES6+ JavaScript. Fast load times and 100% offline-ready.

## 🚀 How to Run Locally

### Option 1: Direct Double Click
Simply double-click [`index.html`](file:///d:/PROJECTS/portfolio/index.html) to open it in Chrome, Edge, or any web browser!

### Option 2: Using the Python Server
Open terminal in `d:\PROJECTS\portfolio` and run:
```powershell
python serve.py
```
This starts a local server at `http://localhost:5500` and automatically opens it in your default browser.

## 🌐 Free 1-Click Hosting Options

You can host this portfolio live on the internet 100% free with:

1. **GitHub Pages**:
   - Create a GitHub repository named `portfolio` (or `<your-username>.github.io`).
   - Push all files from `d:\PROJECTS\portfolio` into the repository.
   - Go to **Settings > Pages** and set source to `main` branch.
   - Your site is live!

2. **Netlify**:
   - Drag and drop the `portfolio` folder directly into [Netlify Drop](https://app.netlify.com/drop).
   - Instant live HTTPS URL!

3. **Vercel**:
   - Import repository or run `npx vercel` inside the folder.
